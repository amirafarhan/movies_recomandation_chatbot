# 🎬 Movie Recommendation RAG Chatbot

An AI-powered movie recommendation chatbot built with **LangChain**, **ChromaDB**, **Hugging Face embeddings** and the **Qwen2.5** LLM.

It uses Retrieval-Augmented Generation (RAG) to answer movie questions using only a custom movie catalog stored in `movies.json` (31 movies across 9 genres).

The chatbot can:

- Recommend movies by genre or by mood/plot description
- Answer questions about specific movies (director, cast, rating, duration)
- Retrieve movie details semantically
- Show which catalog entries were used for every answer

## 🚀 Features

- Load the movie catalog from JSON and convert each movie into a LangChain `Document`
- Semantic search with `sentence-transformers/all-MiniLM-L6-v2` embeddings
- ChromaDB vector store (persisted for the CLI, in-memory for the web app)
- Grounded answers generated by `Qwen/Qwen2.5-0.5B-Instruct`
- **Streamlit web demo** with:
  - Chat interface with example questions and chat history
  - Retrieved movies table with relevance scores and chart
  - Genre filter applied at retrieval time
  - "Search only" mode (no LLM download, instant results)
  - Catalog explorer: rating by genre, rating vs. year, filterable table
- Terminal chatbot and the original Jupyter notebook

## 📦 Installation

```bash
git clone https://github.com/amirafarhan/movies_recomandation_chatbot.git
cd movies_recomandation_chatbot
python -m venv venv
# Windows: venv\Scripts\activate    Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
```

> `requirements.txt` installs the CPU-only build of PyTorch (from download.pytorch.org), which is much
> smaller than the default CUDA build. To use a GPU, install a CUDA build of PyTorch instead.

## ▶️ Run

### Streamlit demo

```bash
streamlit run app.py
```

Open http://localhost:8501. The first question downloads the embedding model (~90 MB) and, if
"Generate AI answer" is on, the Qwen model (~1 GB). Turn the toggle off in the sidebar for
search-only mode.

### Terminal chatbot

```bash
python movie_rag.py
```

### Notebook

Open `MovieRAG.ipynb` in Jupyter and run the cells in order.

## 🧠 How It Works

1. **Load catalog** – `movies.json` maps each genre to a list of movies.
2. **Create documents** – each movie becomes a `Document` with genre, title, year, director, cast, description, rating, duration and language.
3. **Embed** – `all-MiniLM-L6-v2` converts each document into a vector.
4. **Store** – vectors are stored in a Chroma collection (`movies_collection`).
5. **Retrieve** – the most similar movies (default `k=10`) are retrieved for the question, optionally filtered by genre.
6. **Generate** – the retrieved movies are inserted into a prompt that tells Qwen to use **only** the catalog context, or reply *"I don't have that information in the catalog."*

## ⚠️ Notes & Limitations

- The first run is slow because models are downloaded from Hugging Face.
- `Qwen2.5-0.5B-Instruct` is small and samples with temperature 0.3, so answers vary between runs and
  it can occasionally list a retrieved movie under the wrong genre. Use the genre filter for strict
  genre lists, or a larger Qwen model (change `LLM_MODEL` in `movie_rag.py`) for better quality.
- Peak memory is about 2 GB with the Qwen model loaded on CPU (about 0.9 GB in search-only mode).
